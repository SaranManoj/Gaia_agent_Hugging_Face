# GAIA Agent - Hugging Face Agents Course (Unit 4)

A LangGraph agent using Gemini that answers GAIA Level 1 questions.

Tools: web search (DuckDuckGo), Wikipedia, web page reader, Python runner, YouTube video analysis.

## Setup
1. `pip install -r requirements.txt`
2. Copy `.env.example` to `.env` and add your keys
3. Run `agent.ipynb` top to bottom
